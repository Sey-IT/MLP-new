Tenant-Check: Report hochladen

Für den Tenant-Check benötigen wir den Produktreport Ihres Microsoft-365-Tenants inklusive Laufzeiten.

So erhalten Sie den Report

  1. Melden Sie sich im Microsoft 365 Admin Center an.
  2. Öffnen Sie „Abrechnung“ ► „Ihre Produkte“.
  3. Klicken Sie auf „In CSV exportieren“.
  4. Die Datei heißt z. B. Products_2026-05-27T11_24_34+02_00.csv. Laden Sie genau diese Datei hier hoch.

Erlaubt: .csv, .xlsx, .xls – maximal 5 MB
