QR-Code für Teilnehmer-Zertifikate

Trage die Internetadresse ein, unter der das Firmen-Dashboard erreichbar ist (nicht die lokale Datei), und lade den Code für PowerPoint herunter. Der Code enthält Prüfwerte der Namen der im Dashboard angemeldeten Teilnehmer. Erstelle ihn deshalb neu, sobald sich die Anmeldungen ändern.
